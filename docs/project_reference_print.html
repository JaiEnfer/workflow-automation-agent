Project Reference

Workflow Agent

Local AI workflow automation assistant with FastAPI, Ollama, SQLite, and a simplified React frontend for document summarization. Users can paste text or upload PDFs, get readable summaries, and review run history.

Core Outcome

  • Summarizes pasted text and text-based PDFs
  • Falls back safely when the planner returns invalid JSON
  • Stores run history with a health endpoint and report export
  • Uses local Ollama inference rather than hosted AI APIs

Business Problem

Many users want a lightweight local assistant that can summarize documents and orchestrate simple workflow tasks without sending sensitive material to external SaaS analytics or AI platforms. This project provides a private, local-first workflow agent that takes a goal plus user content, plans tool calls with Ollama, and returns readable results with saved history.

Main Inputs

  • Natural-language goal
  • Pasted text content
  • Uploaded text-based PDF files
  • Optional follow-up details when required

Approach

  1. Frontend sends pasted text or extracted PDF text to FastAPI.
  2. Backend merges content into context and asks Ollama for a JSON tool plan.
  3. Planner output is normalized, validated, and executed deterministically.
  4. If planner JSON fails, summarization falls back directly to extracted text.
  5. Run history and reports are stored in SQLite and exposed through the API.

Key AI / System Methods

  • Ollama-based local LLM planning with strict JSON tool-call prompts
  • Pydantic validation for tool arguments and missing-field clarification flow
  • Argument normalization and context filling for planner robustness
  • Direct fallback summarization for malformed planner responses
  • SQLite-backed persistence for runs, audit steps, and reports

Results / Output

The app produces readable summaries for uploaded or pasted content, tracks prior runs, supports follow-up input when details are missing, and serves a cleaner React interface for normal users. Backend health information includes configured and resolved Ollama models, while the ingestion path avoids failing on common planner-formatting errors.
